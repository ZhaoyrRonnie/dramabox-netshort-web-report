# DramaBox vs NetShort Revenue Report

Interactive HTML report for daily revenue trends across Asia and Middle East markets, split by language.

## Contents

- `index.html` - standalone interactive webpage report

## Data Scope

- Date range: January 1 to August 29
- Grain: daily revenue
- Apps: DramaBox and NetShort
- Analysis dimensions: region, language, market, daily lag, and change nodes

Open `index.html` in a browser to view the report.
